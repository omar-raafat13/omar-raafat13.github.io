# Omar Raafat — OD & HR Portfolio

A bilingual (English / Arabic) responsive personal portfolio website.

## Run locally
Open `index.html` in a browser. An internet connection is needed for the Google Fonts.

## Publish with GitHub Pages
1. Create a public repository named `professional-portfolio`.
2. Upload all files and folders in this project (keep `assets/omar-raafat.png` in the assets folder).
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select **main** and **/(root)**, then save.
6. Your site will be published at `https://oraafat13-sketch.github.io/professional-portfolio/`.

## Before publishing
- Review the contact details and external profile links.
- Confirm that all project descriptions are approved for public sharing.
- Add LinkedIn's exact profile URL when available.
- Replace or supplement project illustrations with approved, non-confidential work samples.

The portfolio content is based on the supplied CV and previously discussed professional project areas. No confidential company data or employee data is included.
